# Maine CyberTech Level notification logo

Transparent wordmark PNGs for **Level → Settings → Organization → Logo (Primary/Light)** and **Logo (Dark)**. Level shows the logo in Windows and macOS end-user remote-session notifications.

The wordmark matches the portal website header: **MAINE CYBERTECH** in Orbitron Bold uppercase, with `MAINE` in the foreground colour and `CYBERTECH` in the brand green.

## Upload

1. Open Level **Settings → Organization**.
2. **Logo (Primary/Light):** upload `maine-cyber-tech-level-wordmark-light-3360.png`.
3. **Logo (Dark):** upload `maine-cyber-tech-level-wordmark-dark-3360.png`.
4. Check the Windows and macOS previews, then **Save changes**.

Use the `-1680.png` files if the uploader rejects the 3360px version. Both are PNG with transparent backgrounds; Level accepts PNG or JPG.
