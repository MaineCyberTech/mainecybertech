# SEO Pull Request Checklist

## Metadata

- [ ] Page has unique title.
- [ ] Page has unique meta description.
- [ ] Canonical URL is correct.
- [ ] Open Graph title and description are present.
- [ ] Twitter card metadata is present if supported.

## Page structure

- [ ] One H1 only.
- [ ] H2/H3 hierarchy is logical.
- [ ] Intro explains page purpose clearly.
- [ ] Content satisfies the target search intent.
- [ ] CTA appears near top and bottom.
- [ ] Related internal links are present.

## Technical SEO

- [ ] Page appears in sitemap if public.
- [ ] Private/account/admin pages are not in sitemap.
- [ ] Private/account/admin pages are blocked or noindexed as appropriate.
- [ ] Images have descriptive alt text.
- [ ] Links are crawlable standard links.
- [ ] Page does not require login if intended for public SEO.

## Structured data

- [ ] JSON-LD reflects visible page content.
- [ ] LocalBusiness schema is present on homepage or site shell.
- [ ] Service schema is present on service pages.
- [ ] Article schema is present on blog posts.
- [ ] Breadcrumb schema is present where breadcrumbs are visible.

## Content quality

- [ ] Content is helpful and people-first.
- [ ] No keyword stuffing.
- [ ] No unsupported guarantees.
- [ ] No copied competitor text.
- [ ] Local context is included naturally.
- [ ] Final CTA points to contact page.
