# 60-Module Prompt-Pack Matrix → Real Implementation Map

The prompt-pack matrix at
`prompts/mct-portal-os-expanded-60-modules-deep-prompts-pack/docs/04-implementation-matrix.csv`
lists 60 modules with **aspirational 1-file-per-module paths** that do not
exist. The real modules live in consolidated API routes (62 top-level `.ts`
files under `apps/api/src/routes/`, 75 once `apps/api/src/routes/final/` and
`apps/api/src/routes/store/` are included; this table itself references 49
distinct route files), shared SDK modules under `packages/sdk/src/`, and
admin/portal pages under `apps/web/app/`. The feature specs and runbooks under
`docs/features/` and `docs/runbooks/` use shortened, semantically matching names.

This table is the **real mapping as of 2026-09-27**. The pack files are
SHA-256-pinned by `prompts/manifest.json` and `scripts/verify-prompts.js`:
**never edit the pinned pack files — update this table instead.**

## How to read this table

- Paths are relative to the repo root and wrapped in single backticks.
- `—` means the module genuinely has no artifact for that column.
- Several modules share a consolidated route/SDK file; the **Notes** column
  says which namespace or registration a module uses.
- Worker task files are intentionally out of scope for this table (see the pack
  CSV's worker_task column and `apps/worker/src/tasks/`).
