# Homepage SEO Copy Prompt

Improve the Maine Cyber Tech homepage copy for local SEO.

## Target positioning

Maine Cyber Tech provides managed IT services, cybersecurity, Microsoft 365 support, business Wi-Fi, network installation, UniFi systems, security cameras, cloud backup, disaster recovery planning, and technology consulting for Maine organizations.

## Audience

- Small businesses
- Nonprofits
- Churches
- Marinas
- Warehouses
- Local facilities
- Local organizations with limited internal IT resources

## Required homepage sections

1. Hero
2. Services overview
3. Who we help
4. Why Maine Cyber Tech
5. Common problems solved
6. Technology areas
7. Local service area
8. Call to action
9. FAQ

## SEO requirements

- H1 should include managed IT, cybersecurity, and Maine.
- Mention local business technology support naturally.
- Mention Microsoft 365, Wi-Fi, networks, UniFi, security cameras, cloud backup, and consulting.
- Internal links to all service pages.
- CTA to `/contact`.
- Avoid keyword stuffing.
- Keep copy professional, practical, and trustworthy.

## Output/implementation

If directly modifying the repo:
- Preserve existing components and layout structure.
- Improve copy without large visual redesign unless requested.
- Ensure one H1.
- Add LocalBusiness JSON-LD to homepage or public layout.
