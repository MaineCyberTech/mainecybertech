# Security Camera System Planning Checklist for Maine Businesses

A good security camera system starts with planning. Camera count, placement, cabling, power, storage, remote access, and network design all matter.

This checklist is for Maine businesses, nonprofits, churches, marinas, warehouses, and facilities considering a new security camera system.

## Identify what you need to see

- Entrances and exits
- Parking lots
- Storage areas
- Gates
- Cash/customer areas
- Equipment rooms
- Outdoor assets

## Decide how footage should be stored

- Local NVR
- Cloud storage
- Hybrid approach
- Retention period
- User access controls

## Plan network and power

PoE cameras often require network switches, cable routes, and reliable power. Camera systems should be designed with the network in mind, not added as an afterthought.

## Review remote access needs

Decide who needs access, where they will access from, and what permissions they should have.
