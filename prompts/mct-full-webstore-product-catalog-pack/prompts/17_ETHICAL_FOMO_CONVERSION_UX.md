# 17 Ethical FOMO Conversion UX

Add conversion UX patterns that encourage purchase without damaging trust.

## Requirements

- Add quick-win ladder components: quick win -> bundle -> monthly plan.
- Add help-me-choose quiz or decision guide scaffold.
- Add seasonal readiness modules for marinas, churches/nonprofits, websites, security, and backups.
- Add true limited-capacity messaging only when admin enables it.
- Add trust panels: what is included, no-secret intake, safe-access process, local support, clear exclusions.
- Add mini comparison sections for good/better/best packages.
- Add mobile sticky CTA only if it does not block content.
- Add A/B-test-ready copy variants in config, but do not implement dark patterns.

## Current style requirement

Match current Maine Cyber Tech public/admin styles. Inspect existing marketing and admin components before implementing.

## Mobile requirement

All promo, discount, visual, and admin screens must work on mobile. Product cards must not overflow. Promo badges must wrap cleanly.

## Required button / CTA

Add one primary button for this prompt and make it accessible by role/name.

## Safety requirement

Do not implement fake scarcity, fake countdowns, misleading discounts, or fear-based security manipulation. All urgency must be truthful and admin-auditable.

Suggested button label: **Start With a Quick Win**
