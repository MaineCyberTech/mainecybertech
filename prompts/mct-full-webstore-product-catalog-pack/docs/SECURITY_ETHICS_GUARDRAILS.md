# Security and Ethics Guardrails

## Never collect in public forms

- Passwords
- MFA codes
- Recovery codes
- API keys
- Private keys
- Seed phrases
- Full payment card data
- Regulated records or sensitive personal records

## Promotion ethics

Allowed:

- Real discounts
- Transparent credits
- Real seasonal scheduling recommendations
- Real capacity notices
- Included add-ons with clear scope

Not allowed:

- Fake countdown timers
- Fake scarcity
- Misleading strikethrough prices
- Hidden promo terms
- Fear-based breach pressure
- Unsupported compliance/security guarantees

## Admin audit expectations

Every promotion, visual asset, quiz change, seasonal campaign change, trust badge placement, and quote status change should be audit-log compatible if the existing portal audit pattern supports it.
