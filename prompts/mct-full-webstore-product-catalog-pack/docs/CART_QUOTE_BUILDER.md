# Cart / Quote Builder

## Purpose

Let customers add quick wins, bundles, monthly plans, and add-ons to a quote request without forcing immediate ecommerce checkout.

## Public flow

- Add quick wins/services to quote.
- Recommend a bundle when selected products overlap.
- Show promo eligibility.
- Show consult-required warnings for sensitive services.
- Submit quote request.

## Admin flow

- Review quote request.
- See selected services, intake answers, promotions, and recommended bundles.
- Convert later into ticket, project, lead, or client onboarding workflow.

## Guardrails

- Quote request is not a final contract unless human-approved.
- No payment capture is required in this module.
- No secret collection.
- Sensitive services require consultation.
