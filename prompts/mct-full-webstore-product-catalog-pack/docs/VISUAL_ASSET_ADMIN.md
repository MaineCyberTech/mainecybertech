# Visual Asset Admin

## Purpose

Give admins control over how products, categories, campaigns, and bundles are visually represented.

## Controls

- Pick icon.
- Pick accent color.
- Pick/upload/select hero image.
- Add alt text.
- Mark image as decorative.
- Track provenance: generated, stock, uploaded, internal brand asset.
- Add license notes.

## Guardrails

- No unauthorized vendor logos.
- Alt text required for meaningful images.
- Decorative images should be marked decorative.
- Stock provenance should be recorded.
- Do not imply stock people or brands endorse Maine Cyber Tech.
