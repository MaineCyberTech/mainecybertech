# Service Finder Quiz

## Purpose

Help customers choose a quick win, bundle, and monthly plan based on 4-6 easy questions.

## Required result

Each quiz completion should recommend:

- One quick win.
- One bundle.
- One monthly/recurring plan.

## UX requirements

- Friendly, brief, mobile-first.
- No jargon unless explained.
- Show progress indicator.
- Allow "not sure" answers.
- Do not require account creation.
- Let the customer add recommendations to quote request.

## Admin options

- Edit questions.
- Edit options.
- Map answers to recommended products.
- Preview quiz paths.
- Validate broken recommendation IDs.
