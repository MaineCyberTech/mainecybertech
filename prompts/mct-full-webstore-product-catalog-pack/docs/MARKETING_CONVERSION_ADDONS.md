# Marketing Conversion Add-ons for Maine Cyber Tech Web Store

## Goal

Add conversion-supporting features that make service products easier to understand, compare, and buy without using deceptive urgency or manipulative fear tactics.

## Recommended features

### 1. Ethical discount engine

Add admin-managed promotion rules that support:

- Bundle savings
- Starter credits from quick wins toward larger projects
- New-client foundation offers
- Seasonal readiness offers
- Included add-on offers
- Real capacity notices

### 2. Price-adjacent promo badges

Show discount or offer badges close to the price on product cards and product detail pages. Avoid burying the discount away from the price.

### 3. Bundle compare panels

For bundles, show:

- Included products
- Normal combined range
- Bundle range
- Setup value
- Best-fit customer
- Recommended add-ons

### 4. Quick-win ladder

Use quick wins as low-friction entry points:

- Start with a focused checkup
- Apply recommendations
- Upgrade to bundle
- Move into monthly care

### 5. Ethical FOMO / urgency

Use only truthful urgency:

- Seasonal readiness windows
- Real onsite scheduling capacity
- Real discount end dates
- Real limited introductory offers

Do not use fake countdowns, fake low-stock notices, fake strikethroughs, or fear-heavy security copy.

### 6. Trust builders

Add trust-focused content blocks:

- Plain-English scope
- What is included / not included
- Safe access note
- No-secret intake warning
- Local Maine small-business positioning
- Clear next steps
- Transparent consult-required labels

### 7. Admin promotion controls

The admin center should include:

- Promotion list
- Product eligibility
- Bundle eligibility
- Start/end date
- Promo badge text
- Public/private status
- Audit trail
- Validation warnings

## Discount examples

- "Starter credit eligible: apply part of this quick-win toward a larger security bundle."
- "Bundle savings available when paired with Microsoft 365 Secure Bundle."
- "Includes DNS documentation add-on."
- "Pre-season readiness recommended for marinas and seasonal businesses."
