# Admin Center Requirements

The web store should include a full protected admin center for catalog management.

## Required modules

- Catalog dashboard
- Product list
- Product detail/editor scaffold
- Category manager
- Bundle/recommendation manager
- Intake field manager
- Import/export tools
- Catalog health audit
- Internal fulfillment view, admin-only

## Safety

- Admin-only routes.
- No secret collection.
- Public pages must not expose internal fulfillment procedures.
- Validation before save/import/export.
- Mobile-friendly admin UI.
