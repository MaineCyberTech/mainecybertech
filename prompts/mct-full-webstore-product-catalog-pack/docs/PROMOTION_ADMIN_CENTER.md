# Promotion Admin Center

## Purpose

Allow Maine Cyber Tech admins to create, edit, pause, expire, and audit promotions shown on public product cards, product detail pages, bundle panels, and quote builder surfaces.

## Admin capabilities

- Create/edit promotions.
- Assign eligible products, categories, or bundles.
- Set badge text and expanded detail text.
- Set start/end dates.
- Set terms.
- Set status: draft, active, paused, expired, archived.
- Track audit log entries.
- Preview how the promotion appears publicly.
- Validate promotions before publishing.

## Public display locations

- Product card price area.
- Product detail hero.
- Bundle comparison panel.
- Quote builder line item.
- Seasonal campaign page/card.

## Validation rules

- Active promotions require badge text and terms.
- Date ranges must be valid if both start and end are present.
- Eligibility must target at least one product, category, or bundle.
- Discount claims must not show exact savings unless exact pricing is available.
- Capacity notices must be admin-enabled and truthful.
