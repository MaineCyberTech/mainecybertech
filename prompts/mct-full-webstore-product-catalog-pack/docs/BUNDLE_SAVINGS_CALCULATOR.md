# Bundle Savings Calculator

## Purpose

Help customers understand why a bundle is valuable versus buying standalone quick wins or separate projects.

## Display modes

- Exact savings: use only when exact prices are available.
- Range comparison: use when both standalone and bundle ranges are reliable.
- Included value: use when service scope varies.
- Consult required: use when pricing depends on discovery, hardware, licensing, onsite needs, or risk.

## Recommended public language

- "Included value" instead of exact savings when price ranges vary.
- "Combines the common first steps into one roadmap."
- "Includes documentation and coordinated setup."
- "Final scope confirmed after review."

## Admin controls

- Select bundle.
- Select component products.
- Choose calculation/display mode.
- Add assumptions.
- Add disclaimer.
- Preview display.
