# Admin UX Map for Conversion Modules

## Admin navigation additions

Recommended admin nav group: **Store**

- Catalog Dashboard
- Products
- Promotions
- Bundle Value
- Service Finder
- Seasonal Campaigns
- Visual Assets
- Trust Badges
- Quote Requests
- Audit / Health

## Admin dashboard widgets

- Active promotions
- Expiring promotions
- Draft promotions
- Broken promotion targeting
- Bundle value panels missing assumptions
- Quiz paths with broken recommendations
- Seasonal campaigns enabled
- Visual assets missing alt/provenance
- Submitted quote requests
- Quote requests needing review

## Mobile admin behavior

- Use cards instead of dense tables on phones.
- Keep primary action button visible near top.
- Use filters in collapsible panels.
- Use validation summaries before detailed warnings.
