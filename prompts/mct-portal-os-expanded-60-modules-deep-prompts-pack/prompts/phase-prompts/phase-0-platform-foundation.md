# Phase 0 - Platform Foundation Prompt

Implement the following modules as vertical slices using their corresponding build prompts.

## Modules

- **Internal MSP Business OS Dashboard**: Private operating dashboard for clients, proposals, projects, revenue, renewals, SOP reviews, vendors, tasks, and compliance reminders.
- **Approval Workflow Engine**: Reusable approval system for proposals, change requests, file requests, privileged service desk actions, budget items, procurement, and client sign-offs.

## Instructions

- Use `prompts/MASTER_AGENT_PROMPT.md` first.
- Use each module-specific build prompt.
- Keep changes reviewable.
- Add tests/docs/runbooks with code.
- Run the matching audit prompts before release.
